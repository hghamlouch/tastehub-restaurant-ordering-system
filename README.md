# TasteHub - Restaurant Ordering System

TasteHub is a responsive restaurant ordering website developed using ReactJS.

The website allows customers to browse the restaurant menu, search and filter meals, view food details, add meals to a shopping cart, and complete an order through a checkout page.

## Features

- Responsive Home page
- Restaurant menu
- Search meals
- Filter meals by category
- Food details page
- Add meals to cart
- Cart quantity control
- Remove items from cart
- Automatic total calculation
- Checkout page
- Order confirmation page
- About page
- Contact page
- Responsive design for desktop and mobile

## Installation

1. Clone the repository.

2. Open the project folder.

3. Install the required dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal, usually:

```text
http://localhost:5173/
```
